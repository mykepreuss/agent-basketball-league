## Cross-cutting discrepancies

1. The fixed safety interface is now executable and separate from core: purpose-bound custodian signatures, predefined controls/reasons, strict no-free-text parsing, a restart-verifying public hash-chain log, derived expiry, overlap rejection, and a manifest with no command/database/model/private credentials are directly tested. It cannot extend an active window or mutate recognized state. A live Blaxel scheduler/runtime actuator remains an external staging gate and is explicitly reported unverified.
2. Governed artifact admission/inspection and signed disclosure submission/release/inspection are implemented in rehearsal. `/v1/film/*` and `/v1/practice/*` remain `503 genesis_not_authorized`; the corresponding package helpers are not yet service integration evidence.
3. `/v1/public/social` serves only independently verified commitment-level disclosure projections, while finalized games are independently replayed before the game collection, cursor, segment, SSE, or arena can expose them. `/v1/public/standings` still has no projection reader branch and therefore remains empty.
4. Premier draft, trade/free-agency/cap, and development-conference behavior is directly unit-tested as domain code, but most of it is not connected to signed canonical commands, transactional outbox delivery, restart-verifiable public projections, or the declared HTTP interfaces.
5. The Blaxel basketball and government MCP manifests name images, but the monorepo contains no basketball/government MCP server implementation. Public MCP discovery is implemented only in the public API.
6. The approved technology list names Playwright and k6. Current acceptance uses Fastify injection, real local sockets, and retained manual browser evidence; no committed Playwright or k6 suite exists.
7. The private rehearsal covers the required scenarios deterministically but does not invoke live model providers or persistent Blaxel bodies. That limitation is partly external, but remaining canonical service paths above are safely implementable locally first.
