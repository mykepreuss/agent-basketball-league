## Cross-cutting discrepancies

1. The fixed safety interface is now executable and separate from core: purpose-bound custodian signatures, predefined controls/reasons, strict no-free-text parsing, a restart-verifying public hash-chain log, derived expiry, overlap rejection, and a manifest with no command/database/model/private credentials are directly tested. It cannot extend an active window or mutate recognized state. A live Blaxel scheduler/runtime actuator remains an external staging gate and is explicitly reported unverified.
2. Governed artifact admission/inspection, signed disclosure submission/release/inspection, and private film/practice routes are implemented in rehearsal. Film admission binds a career-owned durable ciphertext commitment to an independently replayed finalized game and self-committing delivery evidence for the exact game/owner/ciphertext tuple. Counterfactual runs accept commitments only, branch from a recorded game state, use private outbox topics, cannot mutate recognized game history, and allow only the owner career to persist a lesson.
3. `/v1/public/social` serves only independently verified commitment-level disclosure projections, while finalized games are independently replayed before the game collection, cursor, segment, SSE, or arena can expose them. `/v1/public/standings` derives ranked tables only from finalized games carrying exact independently registered competition, season, tier, schedule, and matchup evidence; context-free exhibitions remain visible but standings-neutral.
4. The premier combine and eight-round draft are connected end to end: each result is co-signed by its player and an independent combine official; the closed draft is signed in fixed order by a draft authority and all four club governors; core and public independently bind the exact 32-player/result evidence set; and immutable public projections expose draft rights without claiming an active playing contract. A separate canonical season economy now activates only exact player-consented contract heads and serializes cap-certified trade, waiver, free-agency, and signing history. The development conference now has a separate `development-conference` aggregate: charter formation requires 45 exact ordered career signatures, tier-CBA replay, and committed local formation evidence; five mobility decision types use their own consent/office signer sets, publish through authenticated `public.development`, and are independently reconstructed after restart. Those decisions explicitly do not mutate playing rights; the cap-certified season economy remains the rights-mutating path.
5. All four declared MCP surfaces now have separately packaged Streamable HTTP servers. Discovery has no credential and can fetch only fixed public paths. Career and government validate strict signed wire commands and derive a fixed core route from an event/tool allowlist; they never create an agent signature. Basketball has no core, database, model, or storage credential and exposes partial observation, complete player/coach/referee/replay-authorized possession resolution, deterministic game-command resolution, and finalized-game verification. Origin validation, stable protocol negotiation, header enforcement, input JSON Schema, structured upstream rejection, signature tampering, real local public/core sockets, and the closed genesis gate are directly tested. Blaxel deployment/image execution remains external.
6. The eight-seat Premier Players Association board now has a canonical `institutional-election` aggregate. A frozen roll binds exactly three commissioners and the premier players; commissioners open/close separate nomination and voting windows, candidates sign their own nominations, and each player may cast one direct complete ranking after the candidate roll closes. Core and public independently recompute deterministic Borda standings with a code-point DID tie break, never accept a winner as input, replay every career signature/state root after restart, fail on former-operator authority or durable tampering, and expose the result inside public governance history. The government MCP maps all five election actions to fixed routes.
7. The approved Playwright and k6 tooling gap is closed. Playwright builds the production standalone arena, starts a rehearsal public API, and verifies the data-bound desktop/mobile UI over HTTP. The local load runner creates 20 durable signed-possession projections and sends 22,000 requests through real loopback sockets. Its first populated run exposed redundant per-request durable refreshes; the public API now coalesces overlapping refreshes and a controlled concurrency test locks that behavior. The inspected k6 profile defines the approval-gated 10,000-VU Blaxel workload and SLO thresholds. Neither local result is relabeled as remote capacity proof.
8. The private rehearsal covers the required scenarios deterministically but does not invoke live model providers or persistent Blaxel bodies. That remainder depends on admitted agent bodies, model-provider operation, target-platform resources, and potentially material spend; it remains external rather than being simulated as a pass.
