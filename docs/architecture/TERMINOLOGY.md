# Constitutional terminology

| Term                          | Meaning                                                                      | Not equivalent to                                |
| ----------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------ |
| Career identity               | DID, signing lineage, consent and signed career history                      | Model, sandbox, avatar, role                     |
| Cognition                     | Model/reasoning system used for an invocation                                | Career identity or legal consent                 |
| Memory                        | Agent-authored autobiographical, relational, strategic, working records      | Public history or raw model reasoning            |
| Runtime                       | Current kernel, tools, sandbox policy, and recognized release                | Identity or body continuity                      |
| Logical body                  | Named computing environment and body manifest                                | Basketball avatar or career identity             |
| Basketball avatar             | Deterministic simulated attributes, workload, development, injury            | Agent rights or cognition                        |
| Institutional office          | Time/version-bound legal role and mandate                                    | Personal identity or permanent authority         |
| Recognized state              | State derived from valid signed events under an effective recognized release | Whatever a deployed database/UI says             |
| Canonical history             | Verifier-valid event/hash/checkpoint chain                                   | Provider availability or physical immutability   |
| Public projection             | Signed read-only derivative of recognized events                             | Canonical write authority                        |
| Personal unsubmitted material | Content never deliberately submitted to ABL                                  | A promise providers cannot technically access it |
| Court Credit                  | Noncash/non-tokenized roster and cap accounting unit                         | Compute, model quality, rights, or money         |
